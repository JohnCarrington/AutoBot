# prices

**What it does:** Receives live prices from IG for every pair switched on (only GBPUSD now; `docs/PAIRS.md`) and builds them into candles: tick, 5-minute, 1-hour, 4-hour, daily and weekly. Every other part gets its prices and candles from here.

It keeps the buy and sell prices apart in every candle, stores IG's 5-minute candles once IG marks them finished, builds 1-hour, 4-hour, daily and weekly candles from them, keeps each pair's in its own store, `/opt/autobot/data/candles/<PAIR>/` (one file per day per size, UTC, safe writes, never overwritten), and checks the store at start-up and after every new candle. Rules in full: `docs/PRICES_AND_CANDLES.md`.

Files: `model.py` (ticks and candles), `calendar.py` (market hours and candle boundaries), `store.py` (the candle store), `checks.py` (the store checks), `builder.py` (bigger candles from 5-minute ones), `feed.py` (puts it together), `run.py` (a timed live run), `service.py` (the price stream as a service, run by systemd, with the Telegram ready messages and problem alerts), `history_fill.py` (filling recorded gaps and a pair's one-off fill, always for a named pair and only with the owner's go-ahead), `status.py` (the newest candles of each pair), `move_to_pairs.py` (the one-off move of the existing GBPUSD data into its own folder), `long_history.py` (the one-off long fill of IG's own weekly, daily and hourly candles: plan, fetch into a holding folder and compare, then store without overwriting).

**What it must never do:** Never place, change or close a trade. Never ask IG for historical prices except through the history door, and only to fill recorded gaps. Never invent or fill in missing prices: if prices stop arriving, it must say so rather than carry on with old data. Never store a mid price, never overwrite a stored candle (the one exception: a bigger candle built from an incomplete set is rebuilt after a gap fill, and the old one archived), and never delete candles. Never put one pair's prices in another pair's store.
