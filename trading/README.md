# trading

**What it does:** Puts the bot together inside the price service (`engine.py`): after each finished 5-minute candle the analyser takes it, the trade manager runs every open trade on it, the strategies run on it (the same code as the replay) and every idea goes to the order sender, which applies the safety rules before anything is sent; every second, on the latest price, each waiting setup's trigger is checked (copies of the strategies are given the 5-minute candle forming so far), so a trade opens as soon as the live price reaches its trigger, and the trade manager runs the open trades on that price. An idea sent live is not sent again when its candle finishes. At start-up the trade manager's saved state (each open trade's best price so far) is restored. The master switch `TRADING` in `.env`: while it is off everything runs and is recorded, but the order sender is in paper mode and nothing is ever sent to IG.

`python -m trading.replay_check`: over 25 October 21:00 UK to the candle of 9 November 2026 10:00 UTC, the full wired path (strategies, safety rules, order sender in paper mode, trade manager) gives the result of rank 1 in `docs/research/one_view_20261109.md` (the one view at a time rules, design 6): 157 trades, +1120.9 pips, the same won, lost, biggest loss, worst losing run and pips each week, and none of the trades those rules left out.

**What it must never do:** Never log in to IG (it uses the price service's login). Never send an order while `TRADING` is off. Never stop the price service: a problem is reported and trading stops, the prices go on.
